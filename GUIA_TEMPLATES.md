# 📖 Guia Rápido: Templates de Despesas Fixas

## O que são Templates?

Templates são **modelos reutilizáveis** de despesas fixas recorrentes. Em vez de cadastrar manualmente "Aluguel", "Condomínio", "Internet" todo mês, você cria o template uma vez e o sistema gera automaticamente as despesas mensais.

---

## 🚀 Como Usar

### 1️⃣ Criar um Template

1. No menu lateral, clique em **"Templates"**
2. Clique no botão **"Novo Template"**
3. Preencha os campos:
   - **Nome:** Ex: "Aluguel"
   - **Categoria:** Selecione a categoria apropriada
   - **Valor Base:** O valor padrão da despesa (ex: 800.00)
   - **Dia de Vencimento:** Dia do mês que vence (1-31)
4. Clique em **"Criar"**

✅ **Pronto!** O template está criado e ativo.

---

### 2️⃣ Gerar Despesas Mensais

Existem **3 formas** de gerar despesas a partir dos templates:

#### Opção A: Automático (Recomendado)
- Quando você acessar **"Gastos Fixos"** em um mês sem despesas
- O sistema detecta automaticamente que você tem templates ativos
- Aparece uma mensagem perguntando se deseja gerar as despesas
- Clique em **"OK"** para gerar todas de uma vez

#### Opção B: Manual - Todas as Despesas
- Acesse **"Gastos Fixos"**
- Clique no botão **"Gerar dos Templates"** (ícone ⚡)
- Todas as despesas do mês atual serão criadas

#### Opção C: Manual - Despesa Individual
- Acesse **"Templates"**
- Localize o template desejado na tabela
- Clique no ícone **⚡** na coluna "Ações"
- Apenas aquela despesa será gerada para o mês atual

---

### 3️⃣ Ajustar Valores do Mês (Opcional)

Algumas despesas variam de mês para mês (ex: conta de luz, água).

1. Acesse **"Gastos Fixos"**
2. Localize a despesa que deseja ajustar
3. Clique no ícone de **editar** (lápis)
4. Altere o valor específico daquele mês
5. Salve

⚠️ **Importante:** O template permanece inalterado! A alteração é apenas para aquele mês específico.

---

### 4️⃣ Marcar como Pago

1. Acesse **"Gastos Fixos"**
2. Localize a despesa paga
3. Clique no ícone de **check** (✓)
4. Selecione o método de pagamento (PIX, Débito, Crédito, Dinheiro)
5. Confirme

✅ A despesa será marcada como paga com a data e método registrados.

---

## 🔧 Gerenciar Templates

### Editar um Template

1. Acesse **"Templates"**
2. Localize o template na tabela
3. Clique no ícone de **editar** (lápis)
4. Altere os dados desejados
5. Clique em **"Atualizar"**

📝 **Nota:** Alterar o template não afeta despesas já geradas. Apenas novas gerações usarão os valores atualizados.

---

### Desativar um Template

Se você não quer mais que uma despesa seja gerada automaticamente:

1. Acesse **"Templates"**
2. Localize o template na tabela
3. Clique no ícone de **status** (⚡ verde)
4. O template ficará inativo (ícone fica cinza)

💡 **Dica:** Templates inativos não são incluídos na geração automática, mas você pode reativá-los a qualquer momento.

---

### Excluir um Template

⚠️ **Atenção:** Excluir um template também exclui todas as despesas mensais relacionadas!

1. Acesse **"Templates"**
2. Localize o template na tabela
3. Clique no ícone de **lixeira** (🗑️)
4. Confirme a exclusão

---

## 💡 Dicas e Boas Práticas

### ✅ O que cadastrar como Template

- Despesas que se repetem **todo mês**
- Exemplos:
  - Aluguel
  - Condomínio
  - Internet
  - Telefone
  - Plano de streaming
  - Academia
  - Seguro
  - Prestações fixas

### ❌ O que NÃO cadastrar como Template

- Despesas **ocasionais** ou **únicas**
- Despesas que variam muito de valor
- Compras pontuais

Para esses casos, use **"Gastos Variáveis"** ou cadastre manualmente em **"Gastos Fixos"**.

---

### 🎯 Fluxo Ideal Mensal

**Início do Mês:**
1. Acesse **"Gastos Fixos"**
2. Sistema sugere gerar despesas → Confirme
3. Ajuste valores que variaram (ex: conta de luz)
4. Confira se está tudo correto

**Durante o Mês:**
- Marque despesas como pagas conforme for pagando

**Fim do Mês:**
- Revise se todas as despesas foram pagas
- Analise o dashboard para ver o resumo

## 🔄 Cenários Comuns

### Cenário 1: Primeira Vez Usando Templates

**Situação:** Você já tem despesas cadastradas manualmente.

**Solução:**
1. Crie os templates das suas despesas recorrentes
2. No próximo mês, deixe o sistema gerar automaticamente
3. Não precisa migrar dados antigos

---

### Cenário 2: Mudança de Valor Permanente

**Situação:** O aluguel aumentou de R$ 800 para R$ 850.

**Solução:**
1. Acesse **"Templates"**
2. Edite o template "Aluguel"
3. Altere o valor base para 850.00
4. A partir do próximo mês, será gerado com o novo valor

---

### Cenário 3: Despesa Temporariamente Suspensa

**Situação:** Você cancelou a academia por 3 meses.

**Solução:**
1. Acesse **"Templates"**
2. Desative o template "Academia"
3. Quando voltar, reative o template

---

### Cenário 4: Esqueci de Gerar as Despesas

**Situação:** Você pulou a sugestão automática e agora precisa gerar.

**Solução:**
1. Acesse **"Gastos Fixos"**
2. Clique em **"Gerar dos Templates"**
3. Pronto! Despesas criadas

## ❓ Perguntas Frequentes

### 1. Posso ter despesas fixas sem usar templates?

**Sim!** O sistema funciona das duas formas:
- Com templates: Automático e prático
- Sem templates: Manual, cadastrando mês a mês

### 2. Se eu editar uma despesa mensal, o template muda?

**Não!** Editar a despesa mensal não afeta o template. São independentes.

### 3. Posso gerar despesas de meses futuros?

**Atualmente não.** O sistema gera apenas para o mês atual. Mas você pode trocar o mês/ano em "Gastos Fixos" e gerar para cada mês desejado.

### 4. O que acontece se eu gerar duas vezes no mesmo mês?

**Nada!** O sistema detecta duplicatas e não cria despesas repetidas. Você verá uma mensagem informando quantas foram puladas.

### 5. Posso ter templates com o mesmo nome?

**Sim**, mas não é recomendado. Pode gerar confusão. Use nomes descritivos e únicos.

## 🆘 Problemas Comuns

### Problema: Despesas não estão sendo geradas

**Possíveis causas:**
1. Templates estão **inativos** → Ative-os
2. Despesas já existem para o mês → Sistema previne duplicatas
3. Erro de conexão → Verifique o backend

---

### Problema: Template foi excluído por engano

**Solução:**
1. Recrie o template com os mesmos dados
2. Gere as despesas mensais novamente
3. **Prevenção:** Sempre confirme antes de excluir
